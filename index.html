JobFit

A local agent that reads three job posts and one resume, searches each company, scores fit, and prints a ranking.

No paid API. Llama 3.2 runs through Ollama on the same machine. This page does not call the model.

Steps

  1. Extract skills that appear in the job text.
  2. Search the web for the company.
  3. Score the resume and draft 5 bullets.
  4. Repeat for each job, then sort by score.

Sample jobs

  • Northstar Robotics — agent engineer
  • Harbor UI — frontend engineer
  • Fieldnote — AI engineer

Sample rank

85 - agent-job - missing: evals, React
75 - frontend - missing: Python, APIs
55 - robotics - missing: tool calling, measure agent correctness

The rank is a demo. The local model drifts between runs and sometimes invents experience.
